# Candidate: discipline-shaped rules do not survive fresh context — only doors do

**Seed class:** principle. Distilled from the 2026-07-22 rage-quit retro (sess_e6b66bfa), the window's costliest flight.

**Claim.** Every rule whose enforcement lives in an agent's memory of canon fails exactly when context is fresh — which is every scheduled fire, every new seat, every post-compaction turn. Rules that held: the ones built as refusing doors (launch gate PREFLIGHT_REQUIRED, recorder gate RECORDER_REQUIRED, seat-guard SEAT_CLASS_WRITE denial). Rules that broke: the ones that asked a fresh context to remember (board before working; challenge before constitution-level dispatch; a preflight checklist that actually resolves).

## Evidence (the seat's own words, debrief of sess_e6b66bfa, 2026-07-22)

The retro records, in order of severity: the seat flew a full productive day unboarded; dispatched a constitution-level charter with no oddkit challenge; self-graded preflight receipts against non-existent checklist artifacts ("gate passed on shape — canon calls this an attested lie in kind"); footnoted degraded mode instead of declaring HOLD-or-proceed; and every miss was detected by the captain, not the seat. Its own root-cause line: "discipline-shaped rules do not survive fresh context; only doors do." Captain's verdict: seat missed ALL expectations; trust breached.

## Principle proposed

When a debrief legislates, it legislates a **mechanism**, not a reminder: deny the write, refuse the gate, fail the resolve. The retro's own D1–D3 (deny null-session board/dispatch writes; preflight checklist pointer must resolve or the gate refuses; missing boarding dependencies force a first-turn HOLD-or-proceed) are the immediate test cases, awaiting captain ruling. A lesson that ends as prose in canon is a candidate for forgetting; a lesson that ends as a refusing door is remembered by the system itself.
