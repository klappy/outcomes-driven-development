# A Paid-For Workaround Must Transfer to Sibling Routines

**Observation.** The scheduled-sandbox GitHub wall was paid for once
(sess_d7ab9a48, 2026-07-23) and solved once: the git relay Worker. The
distillation routine carries the fix in its charter and pushes nightly. The
sweep routine — same sandbox class, same account, fired the same evening —
has recorded "GitHub unobservable, parity_check not run" as a carried
limitation for three consecutive sweeps, because the fix lives in one
charter's prompt instead of in lane canon.

**The gap.** A lesson encoded as charter folklore protects only the charter
that learned it. Sibling routines re-pay the tuition nightly as silently
skipped checks (parity_check has not run since 07-23), which is quieter and
therefore worse than a crash.

**Proposed rule.** When a flight pays for a lane-level workaround, the
debrief files it against the LANE (dispatch-flight-rules or a lane policy
doc), not only into the surviving charter's prompt — and the next
distillation checks whether sibling routines on that lane still carry the
solved limitation.
