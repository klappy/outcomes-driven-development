# Day-Part Language Derives From the Clock, Not From Session Start

**Single-incident evidence — flagged as such.** This seed names a pattern
observed once this shift; it is recorded because the mechanism it proposes
is general, not because the incident count clears an independence bar.

## The incident

The seat used "tonight" in narration after dawn had passed, despite
observing `oddkit_time` every turn per standing practice. The observation
was happening; the application to word choice was not. Caught by the
captain.

## The proposal

Law: day-part language ("tonight," "this morning," "this afternoon") is
derived from the currently observed civil time, not from when the session
started or what the narration has been calling it up to that point. A
session that began at night and is still running at dawn is, from that
point forward, a morning session in its own words — observation without
application to the very next sentence is not observation that counts.

## Evidence

One incident (this shift). No cross-session recurrence yet observed.
Recorded because the gap it names — checking a fact every turn without
letting that fact govern phrasing — is a general failure shape (the same
shape as citing a source without reading it), not because this instance
alone establishes a pattern.

## Open question for ratification

Whether this needs a mechanical check (a lint on debrief/narration text
against the observed `oddkit_time` civil hour) or is sufficiently corrected
by naming it is not resolved here.
